# Security & Privacy Policy

## 🔒 Privacy & Data Handling Statement

**Field Day Analytics** is built on a privacy-first, zero-telemetry architecture.

- **100% Client-Side Processing**: All ADIF log parsing, QSO entry calculations, geographical mapping, statistical analysis, and report generation take place locally within your browser using JavaScript/TypeScript.
- **No Cloud Uploads**: Log files (`.adif`, `.adi`), callsigns, operator names, grid locators, or contest statistics are **never** transmitted to remote servers, analytics services, or third-party databases.
- **Offline / Local Execution**: Once loaded, the application operates entirely within your browser runtime without requiring persistent internet connections to parse logs or calculate scores.

## 🛡️ Reporting a Security Vulnerability

If you discover a security vulnerability or potential privacy issue in Field Day Analytics, please report it responsibly so we can address it promptly.

### How to Report

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, please send an email or private message to:
- **Email**: `issues@alexsweeney.tech` or via [ke8vxg.radio](https://ke8vxg.radio)
- **GitHub**: [@x2110311x](https://github.com/x2110311x)

### What to Include
