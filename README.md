**Field Day Analytics** is a modern, high-performance web application designed for amateur radio operators, contest stations, and field clubs participating in **ARRL Field Day**. It provides instant log analytics, interactive ARRL section sweep maps, real-time score calculations according to official ARRL rules, operator leaderboards, an integrated user guide, and print-ready summary reports.

---

## 🔒 100% Privacy & On-Device Processing

> **Your log files and operator data never leave your web browser.**

Field Day Analytics runs completely client-side. When you upload ADIF log files, all parsing, geographic mapping, statistical analysis, and report generation occur strictly in your local browser runtime. No log entries, callsigns, grid locators, or contest data are transmitted to any external server or saved in cloud databases.

---

## ✨ Key Features

- **📄 Universal ADIF Log Parser**:
  - Drag-and-drop or select standard `.adif` / `.adi` log files generated by popular logging software (N1MM Logger+, WSJT-X, Ham Radio Deluxe, N3FJP ACLog, MacLoggerDX, etc.).
  - Automatic metadata discovery: extracts club callsign, entry class, transmitter count, home grid square, and section automatically from log headers and entries.
  - Dedicated **GOTA (Get On The Air)** station log support with separate GOTA bonus point tracking.

- **📊 Comprehensive Scoring Engine**:
  - Automated calculation of QSO points per mode.
  - Power multiplier calculations.
  - ARRL Bonus Points checklist.
  - Dedicated GOTA bonus calculation.

- **🗺️ Interactive ARRL Section & Propagation Maps**:
  - Interactive North American section map highlighting all ARRL sections worked.
  - Visual tracking of **Section Sweep** progress towards 100% completion.
  - Geographic grid map displaying QSO density and Maidenhead locator propagation bearings.

- **📈 Visual Analytics & Leaderboards**:
  - Band breakdown charts (160m down to 70cm and microwave).
  - Mode distribution charts.
  - Hourly QSO rate timeline.
  - Individual Operator & Station leaderboards.

- **📖 Integrated User Guide & Instructions Modal**:
  - Step-by-step user guide covering overview, log import rules, station setup, bonus checklist, and PDF report export.

- **📄 Print-Ready Summary Reports & Log Inspection**:
  - Generate clean summary reports using native browser print capabilities (`window.print()`).
  - Interactive Log Grid with filtering, search by callsign/section/mode/band, and inline QSO deletion.
  - Built-in sample log generator for instant testing and demonstration without uploading personal logs.

## 🚀 Quick Start

### Prerequisites

- [Node.js](https://nodejs.org/) (v18.0 or higher recommended)
- [npm](https://www.npmjs.com/) (v9.0 or higher)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/x2110311x/FieldDayStats.git
   cd FieldDayStats
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to `http://localhost:3000` to access the application locally.

## 🛠️ npm Scripts

| Script | Command | Description |
| :--- | :--- | :--- |
| `npm run dev` | `vite` | Starts local development server with hot module replacement (HMR) |
| `npm run build` | `vite build` | Compiles production assets into the `dist/` directory |
| `npm test` | `vitest run` | Runs unit tests using Vitest |
| `npm run preview` | `npm run build && wrangler dev` | Previews production build using Cloudflare Wrangler |
| `npm run deploy` | `npm run build && wrangler deploy` | Deploys the application directly to Cloudflare Pages |

```
FieldDayStats/
├── .github/workflows/    # CI/CD Workflows (build.yml, test.yml)
├── src/
│   ├── components/       # React UI components (Dashboard, Maps, Charts, Reports, LogGrid, Modals)
│   │   ├── InstructionsModal.tsx  # User guide & step-by-step instructions modal

│   │   └── ...
│   ├── services/         # Core business logic modules
│   │   ├── analytics/    # Operator leaderboards & station statistics engine
│   │   ├── geo/          # ARRL section mapping & Maidenhead grid conversions
│   │   ├── parser/       # ADIF log file parsing & metadata extraction
│   │   ├── pdf/          # Native print wrapper (window.print())
│   │   └── scoring/      # Official ARRL Field Day scoring rules & bonus tracking
│   ├── types/            # TypeScript interfaces & type definitions
│   ├── constants.ts      # Application metadata, sample logs, ARRL section database
│   ├── App.tsx           # Primary application container and state management
│   └── main.tsx          # React application entrypoint
├── public/               # Static assets & map data
├── index.html            # HTML entry document
└── vite.config.ts        # Vite configuration & Cloudflare integration
```
